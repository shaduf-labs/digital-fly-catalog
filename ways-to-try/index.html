Ways to try the fly

Try a fly brain in a computer: online demos and no-install options

You do not need to install anything to see a simulated fruit fly brain at work. We found 34 pages that run in a browser or a free online notebook (one of them is a live stream). Start with a browser demo, move to a notebook if you want to change something, and download code only when you are ready to run it yourself.

  • No-install links: 34 (3 added on 30 Sep 2026)
  • Checked: 30 Sep 2026, all answered (HTTP 200)
  • Played by us: none yet

Want to see a demo before you open one? Watch the demos in the Video gallery: 49 videos, each with the project's evidence grade and what the video does not show.

Four levels of effort

  1. Level 1Open in a browserNothing to install. Watch or play with a demo that runs in the page.Browser demos
  2. Level 2Run a notebookA free online notebook runs real research code for you. You can change a number and run it again.Notebooks
  3. Level 3Download and runInstall Python or an app and run a project on your own computer.Download and run
  4. Level 4Build your ownFollow our guide from an empty folder to your own small project.Build your own

What our check labels mean

  • Page respondsThe link answered on the check date (HTTP 200), but we did not play the demo. It may still need a special browser, a sign-in or a fast computer. Every link on this page has this label in the current release.
  • Opened and usedWe loaded the demo in a real browser and used it. The device and browser are listed with the date. No demo has this label yet; we plan to test demos in a real browser in a later run.
  • DownloadNeeds an install. We give the platform and download size when the authors state them.

A demo that opens is not the same as a demo driven by the fly's brain. Each row also shows the project's evidence grade: A and B mean a real connectome drives the behaviour; C, D and U mean most of what you see comes from other code, or we could not check.
