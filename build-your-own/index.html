Build your own fruit fly brain simulation: a tested beginner guide from an empty folder

Run the published whole-brain model of the fruit fly on an ordinary CPU. You give 21 sugar-sensing neurons a taste, the simulated brain of 138,639 neurons responds, and you read out the neuron that makes a fly extend its proboscis to feed. Then you change one thing and check the result against shuffled wiring.

  • Tested on: Linux x86_64 (Debian 12), Python 3.11.2, 2 CPUs, no GPU, no C++ compiler, 28 Sep 2026; re-tested from an empty folder on 1 Oct 2026 and 5 Oct 2026; "Add a body" (brain to a FlyGym fly) tested on 2 Oct 2026; "Add a sense: looming" tested on 5 Oct 2026 (two more body runs on 8 Oct 2026); brain and body in one environment tested on 8 Oct 2026
  • Full run: 28 min for 20 one-second trials; tests 52 s
  • Untested: macOS, Windows/WSL, Colab, machines with a compiler
  • Pins: unchanged; checked against PyPI on 8 Oct 2026 (latest: Brian2 2.10.1, numpy 2.5.3, pandas 3.0.6, mujoco 3.15.0; our pins stay at 2.9.0, 2.3.5, 2.3.3 and 3.9.0) and installed cleanly in the re-test of 5 Oct; Brian2 2.9.0 does not import with numpy 2.5.3 (common errors); next re-test due 19 Oct 2026
  • Download: 104.1 MB of FlyWire data for the beginner path (what you download)

Use in class: does a fly's wiring map do anything? (20 minutes)

Secondary or first-year university class; the teacher runs the commands, the class reads and discusses the numbers. It uses the beginner path of this guide (sugar neurons → the feeding motor neuron MN9) and the Shiu et al. model on FlyWire v783.

The plan

  1. 0-3 min The question. Ask: a brain scan is a map of which neurons connect. Can a map do anything? Read the plain answer 'Is it a brain or just a map?' aloud. Source: our plain answers.
  2. 3-6 min Taste sugar. Run one sugar trial (21 sugar-sensing neurons stimulated at 150 spikes per second for 1 s). It takes about 73 s; while it runs, explain that MN9 is a motor neuron used for feeding.
  3. 6-9 min Read the result. MN9 fires at 82.0 spikes per second. The same number came out in every re-test (bit-exact), so the class can check it.
  4. 9-13 min Scramble the map (the control). Show our degree-preserving shuffles: every neuron keeps its number of connections but the partners are mixed up. In all 5 shuffles MN9 stayed at 0 spikes per second. Ask: what does this tell us about the wiring? (Results shown from our run 5 test; the beginner project has no shuffle command, so this is not run live.)
  5. 13-15 min A shadow from one side (the looming result). Read this sentence aloud: We ran the map. A looming shadow on one eye turned our simulated fly away in 6 of 6 runs. With the same map scrambled (same number of connections per neuron) it turned away in 0 of 3. Here the map's wiring, not the stimulus or our code, makes the turn. Then add: one model, brain plus simulated body, not a real fly; the body does the walking with its own controller, and the rule that turns neuron rates into leg commands is ours. Source: our looming test, 5 and 8 Oct 2026.
  6. 15-20 min Discuss. Pick two or three of the questions below.

Questions for the discussion

  1. The model got 82 spikes per second from the real map and 0 from a scrambled one. Does that make it a brain, or still a map? What does the model leave out?
  2. Every connection comes from the fly's wiring and one strength is set by hand; nothing is learned. Is this AI? What changes when a demo adds a trained part?
  3. Real fly larvae have sensory neurons that detect harmful heat and pressure. Is detecting harm the same as feeling pain? Could a program that copies the wiring suffer?

What you will build, and why this project

A small Python project, taste → action, that wraps the leaky integrate-and-fire (LIF) model of Shiu et al. (Nature 634, 210–219, 2024), philshiu/Drosophila_brain_model, pinned at commit 91bdd1e7, with the FlyWire connectome public release v783. We chose it because:

  • It is the real thing, and small enough. The whole adult brain wiring runs on a CPU, with about 105 MB of data.
  • It was tested against flies. The paper compared the model's predictions with experiments (grade A in our catalogue), so you have published numbers to compare with. Its requirements, known issues and the projects built on it are on its project page.
  • Most viral demos reuse it. Once you understand this project, you can read the code of DOOMFLY, Fly64 and many browser demos.
  • The code licence is MIT. The data licence is non-commercial; see the licence box.

What the model leaves out

This is a model, so it does not show what a living fly would do. In the authors' words, it "does not account for gap junctions, non-spiking neurons, internal state or long-range neuropeptides, and assumes that the basal firing of each neuron is zero". It has no neuromodulation, no learning (plasticity) and no body, and the transmitter signs are predictions. The authors say they do not trust absolute firing rates; compare patterns, not exact numbers.

How to tell it worked

  1. pytest prints 6 passed.
  2. With sugar at 150 Hz, MN9 fires at roughly 80–90 Hz and the action is "EXTEND proboscis".
  3. With no stimulus, nothing fires. The model has no spontaneous activity, so any spike there means a bug.
  4. With shuffled wiring, MN9 stays at 0 Hz while the sugar neurons still fire at about 147 Hz.

With the same seed, a 100 ms trial gave exactly 1,200 whole-brain spikes in three separate runs on our machine. Other CPUs or library versions may give slightly different spike counts (Untested).

Customize it

Open a Python prompt in the folder with .venv/bin/python, then:

import fly_taste as ft

# 1. Change the stimulus rate (tested: 50 Hz gave 16.6 ± 7.2 Hz)
r = ft.run_condition(ft.SUGAR_GRNS_V783, rate_hz=50, n_trials=5)
print(ft.rate_of(r, ft.MN9))

# 2. Silence a neuron (tested: this one cut MN9 by 34%)
r = ft.run_condition(ft.SUGAR_GRNS_V783, silence_ids=[720575940623211725], n_trials=5)
print(ft.rate_of(r, ft.MN9))
  • Silencing cuts outgoing synapses only. As in upstream silence(), only the synapses from the neuron are set to zero, although the upstream Readme says "to and from" (issue #10, open). To cut its inputs too, also zero syn.w['j == k'].
  • Why this neuron? run_demo.py picked it with our own rule: the input to MN9 with the largest synapse count × firing rate in the sugar run, not counting the sugar neurons. It makes 424 synapses onto MN9 (FlyWire cell type CB0553, predicted acetylcholine). Silencing it weakened MN9 but did not stop it, which suggests other excitatory routes. This is a model output; it is not one of the paper's experiments.
  • Other neurons: use v783 IDs. FlyWire IDs change when a neuron is edited. Look them up in FlyWire Codex with the version set to 783. The upstream notebooks list v630 IDs, and one sugar neuron changed: 720575940620900446 (v630) is 720575940639259967 in v783, as the upstream author wrote in issue #7. The other 20 sugar neurons and MN9 (720575940660219265) are unchanged.

The shuffled-wiring control, and why it matters

A shuffled brain keeps everything except who connects to whom. Our control randomly re-assigns the target of each of the 15.1 million connections (shuffle_seed=1 and 2). Every neuron keeps its number of inputs and outputs, and its outgoing weights and sign, so excitatory neurons stay excitatory.

Result: with the same 150 Hz sugar stimulus, MN9 went from 85.2 Hz to 0 Hz in 6 of 6 trials. The sugar neurons still fired at about 147 Hz, but activity reached only 120–126 neurons instead of 409. So the response depends on the specific wiring, not only on the number or strength of connections. This matches the direction of the paper (shuffled weights activated MN9 in 1 of 100 runs) and of the drosophila-brain-mlx port (0 Hz); we did not re-run those.

This is the test most viral demos skip. When you see a "fly brain" play a game, ask whether it still plays with shuffled wiring. See Is it real? for the demos we checked. With only 2 shuffles this is a clean but small result. On 1 Oct 2026 we ran the fuller version: four kinds of scrambled wiring, five shuffles each, pre-registered. Degree-preserving and weight shuffles gave 0 Hz, a shuffle that keeps the sensory and motor wiring kept 39 Hz, and a sign shuffle made the whole brain fire.

Try a fair control yourself

A fairer control uses more than one kind of shuffle, several shuffles of each, and a second measurement next to MN9: how many spikes the whole brain fires. Our test showed why. A sign shuffle pushed MN9 to 214 Hz, far above the real 85 Hz, only because the whole brain ignited; on MN9 alone it would look like a better reflex.

  1. Pick the null. The three shuffles below are the ones from our test (Python and numpy, MIT licence). Each takes the edge list as three arrays (presynaptic index, postsynaptic index, signed synapse count) and keeps the number of connections and the total synapse count. They passed our unit tests and produced the published results. Run by us 2026-10-01 on Linux
  2. Wire it into the model. fly_taste.py only knows the degree-preserving shuffle (shuffle_seed). To use a weight or sign shuffle, the network has to be built from the shuffled signed counts instead of the upstream ones. We did this in our own trial worker, not in the beginner files, so this step as a beginner change is Untested.
  3. Measure two things. Record MN9 and the whole brain's spike count, and run at least 3 shuffles of each kind. A 1 s trial took us 74 s with the real wiring and about 2 minutes with a sign shuffle, on 2 CPUs.
Three shuffle functions from our fair test (code as run, comments added; MIT) 
import numpy as np

# pre, post: int32 arrays of neuron indices; cnt: int32 signed synapse counts (count x +1/-1).
# Every function keeps the edge order, the number of edges and the total synapse count.

def null_degree(pre, post, cnt, seed):
    # Degree-preserving: permute the postsynaptic column (as fly_taste.load_edges does).
    p = post.copy()
    np.random.default_rng(seed).shuffle(p)
    return pre, p, cnt

def null_weight(pre, post, cnt, seed):
    # Weight shuffle: keep who connects to whom and each edge's sign; permute the sizes.
    a = np.abs(cnt)
    perm = np.random.default_rng(seed).permutation(a.size)
    return pre, post, (np.sign(cnt) * a[perm]).astype(cnt.dtype)

def neuron_signs(pre, cnt, n):
    """Per-neuron sign (+1/-1) for every neuron with outgoing edges, 0 otherwise.
    Raises if a presynaptic neuron has edges of both signs (Dale's law violated in the input)."""
    s = np.zeros(n, dtype=np.int8)
    sg = np.sign(cnt).astype(np.int8)
    s[pre] = sg
    if not np.array_equal(s[pre], sg):
        raise ValueError("input data has a presynaptic neuron with mixed signs")
    return s

def null_sign(pre, post, cnt, seed, n):
    # Sign shuffle with Dale's law: each neuron keeps one sign, signs are permuted across neurons.
    s = neuron_signs(pre, cnt, n)
    has = np.nonzero(s != 0)[0]
    new = np.zeros_like(s)
    new[has] = np.random.default_rng(seed).permutation(s[has])
    return pre, post, (np.abs(cnt) * new[pre]).astype(cnt.dtype)

Add a body: let the brain drive a walking fly (tested 2 Oct 2026)

FlyGym turns a fly toward the side with the smaller number, like a tank that slows one track: our check with 1.0 on the left and 0.3 on the right turned the fly 129° to the right. A fly with only its left P9 active should turn left (Bidaye et al. 2020). If the left legs got the left P9 rate, they would step harder and the fly would turn right, the wrong way. Feeding each side the other side's P9 rate fixes the direction. We made this change before the first body run and logged it as a deviation from our plan. With both P9s active it changes each number by only about 0.1.

"""Taste -> action with the Shiu et al. whole-brain LIF model (FlyWire v783).

What this file does
-------------------
1. Loads the FlyWire v783 connectivity published in philshiu/Drosophila_brain_model
   (measured wiring: who connects to whom, how many synapses, excitatory/inhibitory sign).
2. Builds the same leaky integrate-and-fire (LIF) network as upstream model.py
   (modelled dynamics: equations and parameters are imported from upstream, not copied).
3. Drives chosen sugar-sensing gustatory receptor neurons (GRNs) with Poisson spikes
   (hand-made stimulus: which neurons and what rate are our choice, following the paper).
4. Reads out the firing rate of MN9, the motor neuron for proboscis extension
   (hand-made readout choice, following the paper).
5. Maps the rate to an action with a threshold (hand-made rule, not part of the model).

Differences from upstream run_exp (see README "What's real here"):
- Only the three columns the model uses are loaded, as int32/float arrays, to save memory.
- The connectivity file is streamed in chunks (same synapse order) to keep peak memory under 1 GB.
- Each trial runs in a fresh worker process with an explicit random seed (repeatable runs).
- Brian2 runs with the pure-numpy code generation target when no C++ compiler exists.

def pick_codegen_target() -> str:
    """Cython (fast) if a C++ compiler is on PATH, else pure numpy (slower, needs no compiler).

    Override with the environment variable FLY_CODEGEN=numpy or FLY_CODEGEN=cython.
    """
    forced = os.environ.get("FLY_CODEGEN")
    if forced:
        return forced
    if any(shutil.which(c) for c in (os.environ.get("CXX", ""), "g++", "clang++", "c++") if c):
        # keep Brian2's compiled-code cache inside the project (works on read-only homes too)
        b2.prefs.codegen.runtime.cython.cache_dir = str(HERE / ".cython_cache")
        return "cython"
    return "numpy"


def load_ids() -> np.ndarray:
    """FlyWire root IDs in model order (row i of the CSV = Brian2 neuron index i)."""
    ids = np.loadtxt(COMPLETENESS, delimiter=",", skiprows=1, usecols=0, dtype=np.int64)
    return ids


def _read_column(name, dtype):
    """Read one parquet column row group by row group into a compact numpy array."""
    f = pq.ParquetFile(CONNECTIVITY, memory_map=False)
    out = np.empty(f.metadata.num_rows, dtype=dtype)
    k = 0
    for g in range(f.num_row_groups):  # streaming keeps peak memory low
        col = f.read_row_group(g, columns=[name]).column(0).to_numpy()
        out[k:k + col.size] = col
        k += col.size
        del col
    assert k == out.size
    return out


def load_edges(shuffle_seed: int | None = None):
    """Return (pre, post) neuron indices of every connection, as int32.

    shuffle_seed: if given, build the degree-preserving control by randomly permuting
    the postsynaptic column in place. Every neuron keeps its number of outgoing and
    incoming connections, and every presynaptic neuron keeps its own weights and sign
    (so excitatory neurons stay excitatory), but who-connects-to-whom is randomised.
    """
    pre = _read_column("Presynaptic_Index", np.int32)
    post = _read_column("Postsynaptic_Index", np.int32)
    if shuffle_seed is not None:
        np.random.default_rng(shuffle_seed).shuffle(post)
    return pre, post


def load_signed_counts():
    """Upstream's 'Excitatory x Connectivity' column: synapse count x (+1 excitatory,
    -1 inhibitory). The sign comes from the predicted neurotransmitter of the presynaptic
    neuron (acetylcholine = +1; GABA and glutamate = -1)."""
    return _read_column("Excitatory x Connectivity", np.float64)


def load_connectivity(shuffle_seed: int | None = None):
    pre, post = load_edges(shuffle_seed)
    return pre, post, load_signed_counts()


def build_network(params, exc, slnc, shuffle_seed=None):
    """Build the upstream LIF network (same as create_model() + poi() + silence() in
    upstream model.py), streaming the connectivity file in chunks to keep memory low."""
    n = len(load_ids())
    neu = b2.NeuronGroup(
        N=n, model=params["eqs"], method="linear",
        threshold=params["eq_th"], reset=params["eq_rst"], refractory="rfc",
        name="default_neurons", namespace=params,
    )
    neu.v = params["v_0"]
    neu.g = 0 * mV
    neu.rfc = params["t_rfc"]
    syn = b2.Synapses(neu, neu, "w : volt", on_pre="g += w",
                      delay=params["t_dly"], name="default_synapses")
    f = pq.ParquetFile(CONNECTIVITY, memory_map=False)
    post_all = load_edges(shuffle_seed)[1] if shuffle_seed is not None else None
    k = 0
    for g in range(f.num_row_groups):  # connect chunk by chunk (same order as upstream)
        t = f.read_row_group(g, columns=["Presynaptic_Index", "Postsynaptic_Index"])
        pre = t.column(0).to_numpy().astype(np.int32)
        post = (post_all[k:k + pre.size] if post_all is not None
                else t.column(1).to_numpy().astype(np.int32))
        del t
        syn.connect(i=pre, j=post)
        k += pre.size
    del post_all
    w_syn = float(params["w_syn"])  # 0.275 mV, in volts
    k = 0
    for g in range(f.num_row_groups):  # weight = signed synapse count x w_syn
        c = f.read_row_group(g, columns=["Excitatory x Connectivity"]).column(0).to_numpy()
        syn.w_[k:k + c.size] = c * w_syn
        k += c.size
    for i in slnc:  # same as upstream silence(): zero all synapses *from* neuron i
        syn.w[f"i == {i}"] = 0 * mV
    pois = []
    for i in exc:   # same as upstream poi()
        pois.append(b2.PoissonInput(target=neu[i], target_var="v", N=1,
                                    rate=params["r_poi"],
                                    weight=params["w_syn"] * params["f_poi"]))
        neu[i].rfc = 0 * ms
    mon = b2.SpikeMonitor(neu, record=False)  # spike counts only, saves memory
    return b2.Network(neu, syn, mon, *pois), mon, len(syn)


def _one_trial(params_r_poi_hz, exc, slnc, shuffle_seed, rand_seed, t_run_ms):
    """Build the network, run one trial, return (spike counts, n_synapses, build s, run s).
    Runs in a fresh worker process so all memory is returned after each trial
    (upstream does the same via joblib)."""
    params = dict(default_params)  # upstream constants and equations
    params["r_poi"] = params_r_poi_hz * Hz
    b2.prefs.codegen.target = pick_codegen_target()
    b2.start_scope()
    t0 = time.time()
    net, mon, n_syn = build_network(params, exc, slnc, shuffle_seed)
    t1 = time.time()
    b2.seed(rand_seed)
    net.run(t_run_ms * ms)
    return np.asarray(mon.count[:], dtype=np.int32), n_syn, t1 - t0, time.time() - t1


def run_condition(stim_ids, rate_hz=150.0, silence_ids=(), n_trials=3, t_run_ms=1000.0,
                  seed=0, shuffle_seed=None, verbose=True):
    """Run one experimental condition; return per-trial spike counts for all neurons.

    Like upstream run_trial(), the network is rebuilt for every trial (a few seconds),
    one trial at a time (peak memory about 0.6 GB). Trial k uses Brian2 random seed
    (seed * 1000 + k) for the Poisson input, so runs are repeatable.
    """
    ids = load_ids()
    id2i = {int(f): i for i, f in enumerate(ids)}
    exc = [id2i[int(f)] for f in stim_ids]          # KeyError here = ID not in v783
    slnc = [id2i[int(f)] for f in silence_ids]

    counts = np.zeros((n_trials, len(ids)), dtype=np.int32)
    build_s = sim_s = 0.0
    ctx = multiprocessing.get_context("spawn")
    for trial in range(n_trials):
        with ProcessPoolExecutor(max_workers=1, mp_context=ctx) as ex:
            c, n_syn, tb, tr = ex.submit(_one_trial, rate_hz, exc, slnc, shuffle_seed,
                                         seed * 1000 + trial, t_run_ms).result()
        counts[trial] = c
        build_s += tb
        sim_s += tr
        if verbose:
            print(f"  trial {trial + 1}/{n_trials}: {len(ids)} neurons, {n_syn} synapses, "
                  f"{int(c.sum())} spikes; build {tb:.1f} s, run {tr:.1f} s "
                  f"(target={pick_codegen_target()})", flush=True)
    return {
        "ids": ids, "counts": counts, "t_run_s": t_run_ms / 1000.0,
        "build_s": build_s, "sim_s": sim_s, "target": pick_codegen_target(),
        "stim_rate_hz": rate_hz, "n_trials": n_trials, "seed": seed,
        "shuffle_seed": shuffle_seed, "silenced": [int(s) for s in silence_ids],
    }


def rate_of(result, flywire_id):
    """Mean and s.d. firing rate (Hz) across trials for one neuron."""
    i = int(np.nonzero(result["ids"] == flywire_id)[0][0])
    r = result["counts"][:, i] / result["t_run_s"]
    return float(r.mean()), float(r.std())


def proboscis_action(mn9_rate_hz, threshold=PROBOSCIS_THRESHOLD_HZ):
    """Hand-made action mapping: extend the proboscis if MN9 fires above threshold."""
    return "EXTEND proboscis" if mn9_rate_hz > threshold else "stay still"


def top_active(result, n=10, exclude=()):
    mean = result["counts"].mean(axis=0) / result["t_run_s"]
    order = np.argsort(-mean)
    out = []
    ex = set(int(e) for e in exclude)
    for i in order:
        if mean[i] <= 0 or len(out) >= n:
            break
        if int(result["ids"][i]) in ex:
            continue
        out.append((int(result["ids"][i]), float(mean[i])))
    return out

def strongest_active_input_to_mn9(res):
    """Our (hand-made) choice of neuron to silence: the MN9 input partner with the largest
    (synapse count x firing rate) in the sugar run, excluding the stimulated GRNs."""
    pre, post, wsc = ft.load_connectivity()
    i_mn9 = int(np.nonzero(res["ids"] == ft.MN9)[0][0])
    sel = post == i_mn9
    p, w = pre[sel], wsc[sel]
    rate = res["counts"].mean(axis=0) / res["t_run_s"]
    grn_idx = {int(np.nonzero(res["ids"] == g)[0][0]) for g in ft.SUGAR_GRNS_V783}
    best, best_score = None, 0.0
    for k, wk in zip(p, w):
        score = wk * rate[k]
        if int(k) not in grn_idx and score > best_score:
            best, best_score = int(k), score
    return int(res["ids"][best]), float(best_score), int(sum(w[p == best]))

"""OUR rate-to-drive mapping (hand-made by Digital Fly Lab, run 6, 2026-10-02; pre-registered 2026-10-02T09:35:33Z).

This is NOT part of the Shiu et al. brain model and NOT part of FlyGym. It turns descending-neuron (DN) firing rates
from a brain trial into FlyGym's two-number descending drive (one number per side, as HybridTurningController expects).
Nothing here was fitted or tuned to results. Pure numpy; no FlyGym import. Licence: MIT.

For each 100 ms bin k and side s (o = the other side), rates in Hz, R = 100 Hz fixed in advance:
    p_s = rate(DNp09_s) / R
    m_s = mean rate(MDN on side s) / R
    a_s = rate(DNa02_s) / R
    drive_s(k) = clip(p_s - m_s - 0.5 * (a_s - a_o), -1.2, 1.2)
Each bin's drive is held for 100 ms of body time.

DEVIATION 1 (logged in ../preregistration.md before the first body run): the basis check (../basis.md) found that
unilateral P9 drives IPSILATERAL turning (Bidaye et al. 2020: "P9 drives forward walking with ipsilateral turning").
With p_s on its own side, P9_L alone gives drive (p, 0): the left legs step, the right legs stand, and the fly turns
right (contralateral). The fix used for every body run:
    drive_s(k) = clip(pbar - 0.5 * (p_s - p_o) - m_s - 0.5 * (a_s - a_o), -1.2, 1.2),  pbar = (p_L + p_R) / 2
i.e. forward = mean P9 rate, plus an ipsilateral P9 turning term with the same 0.5 gain as DNa02. Algebraically
pbar - 0.5 * (p_s - p_o) = p_o, so each side's forward term is the OTHER side's P9 rate. Under bilateral P9 with
equal rates nothing changes. `drive_from_rates_prereg` keeps the pre-registered formula for comparison.
"""

           "-1.2, 1.2) with p = rate(DNp09)/R, pbar = mean of both sides' p, m = mean rate(MDN)/R, a = rate(DNa02)/R, "
           "R = 100 Hz, per 100 ms bin, held 100 ms; s = side (left, right), o = the other side. Pre-registered "
           "version: forward term p_s; changed to the ipsilateral-turning P9 term before the first body run "
           "(deviation 1, after the basis check)")

def drive_from_rates_prereg(p, m, a):
    """The pre-registered formula (forward term p_s). Kept for comparison; not used for the body runs."""
    p, m, a = (np.asarray(x, dtype=float) / R_HZ for x in (p, m, a))
    turn = a - a[:, ::-1]  # a_s - a_o
    return np.clip(p - m - 0.5 * turn, -CLIP, CLIP)


def drive_from_rates(p, m, a):
    """p, m, a: arrays of shape (n_bins, 2) in Hz, columns (left, right). Returns drive (n_bins, 2).
    Deviation 1: the P9 term turns ipsilaterally (pbar - 0.5*(p_s - p_o) = p_o)."""
    p, m, a = (np.asarray(x, dtype=float) / R_HZ for x in (p, m, a))
    pbar = p.mean(axis=1, keepdims=True)
    p_turn = p - p[:, ::-1]  # p_s - p_o
    a_turn = a - a[:, ::-1]  # a_s - a_o
    return np.clip(pbar - 0.5 * p_turn - m - 0.5 * a_turn, -CLIP, CLIP)


def rates_from_trial(trial: dict, n_bins: int = 10):
    """Per-bin rates (Hz) of the six candidate cell types per side from a run 6 brain trial file (field 'dn')."""
    bins = {int(x["id"]): x["bins"] for x in trial["dn"]["active"]}
    scale = 1000.0 / trial["dn"]["bin_ms"]
    out = {}
    for ct, sides in DN_IDS.items():
        out[ct] = {}
        for side, ids in sides.items():
            arr = np.array([bins.get(i, [0] * n_bins) for i in ids], dtype=float) * scale
            out[ct][side] = arr.mean(axis=0)  # mean over the neurons of this type on this side
    return out


def drive_from_trial(trial: dict):
    r = rates_from_trial(trial)
    col = lambda ct: np.stack([r[ct]["left"], r[ct]["right"]], axis=1)
    return drive_from_rates(col("DNp09"), col("MDN"), col("DNa02")), r

def queue(drives_dir, out_dir, order, start_cut, kill, log):
    sc = datetime.fromisoformat(start_cut.replace("Z", "+00:00")).timestamp()
    kl = datetime.fromisoformat(kill.replace("Z", "+00:00")).timestamp()
    Path(out_dir).mkdir(parents=True, exist_ok=True)

    def L(r):
        with open(log, "a") as f:
            f.write(json.dumps(r) + "\n")
    for cid in order:
        d = Path(drives_dir) / f"{cid}.json"
        o = Path(out_dir) / f"{cid}.json"
        if o.exists() or not d.exists():
            continue
        if time.time() >= sc:
            L({"event": "start-cut", "run": cid, "at": now()})
            break
        m = mem()
        waited = 0
        while m is not None and m > 2.4 * GIB and waited < 180:
            time.sleep(30)
            waited += 30
            m = mem()
        if m is not None and m > 2.6 * GIB:
            L({"event": "skipped-memory", "run": cid, "mem": m, "at": now()})
            continue
        L({"event": "start", "run": cid, "mem": m, "waited_s": waited, "at": now()})
        t0 = time.time()
        p = subprocess.Popen([sys.executable, __file__, "one", str(d), str(o)], env=dict(os.environ, BODY_MEM_AT_LAUNCH=str(m or 0)))
        try:
            rc = p.wait(timeout=max(1, min(120, kl - t0)))
        except subprocess.TimeoutExpired:
            p.kill()
            p.wait()
            if time.time() >= kl - 1:
                L({"event": "killed-at-kill-time", "run": cid, "at": now()})
                break
            rec = {"id": cid, "status": "timeout", "wall_s": round(time.time() - t0, 1), "finished_at": now()}
            Path(str(o) + ".tmp").write_text(json.dumps(rec))
            os.replace(str(o) + ".tmp", o)
            L({"event": "timeout", "run": cid, "at": now()})
            continue
        L({"event": "end", "run": cid, "rc": rc, "wall_s": round(time.time() - t0, 1), "at": now()})
    L({"event": "queue-done", "at": now()})

def unwrapped_heading(v):
    """Heading change over the driven period, unwrapped sample by sample (10 ms). The run 6 body files store
    heading_deg wrapped to (-180, 180], which misreads spins of more than 180 deg (the P9L runs)."""

"""Null (scrambled-wiring) generators and property checks for the fair test (Digital Fly Lab, run 5).

Licence: MIT (same as the bootstrap project). Pre-registration: ../preregistration.md.

Every generator takes the real edge list as numpy arrays
    pre   int32 [E]  presynaptic neuron index (Brian2 index = row of Completeness_783.csv)
    post  int32 [E]  postsynaptic neuron index
    cnt   int32 [E]  signed synapse count (upstream "Excitatory x Connectivity": count x +1/-1)
and returns new (pre, post, cnt) arrays. Edge order is kept, so the number of edges and the
total synapse count (sum |cnt|) are always unchanged.

Arms (null_type in the controls ledger):
  D  degree-preserving   permute the post column over all edges (identical to the bootstrap
                         fly_taste.load_edges(seed): np.random.default_rng(seed).shuffle(post))
  W  weight-shuffle      permute |cnt| over all edges; graph and each edge's sign kept
  S  sign-shuffle        permute the per-neuron transmitter sign over presynaptic neurons
                         (Dale's law: one sign per neuron); graph and |cnt| kept
  B  boundary-preserving permute the post column over interior edges only (pre not on the input
                         side and post not on the output side); boundary edges unchanged
  B' other               permute the post column over all edges except those out of the stimulus
                         neurons and those into the readout neuron
"""
from __future__ import annotations

import hashlib

import numpy as np


# ---------------------------------------------------------------- generators
def null_degree(pre, post, cnt, seed):
    p = post.copy()
    np.random.default_rng(seed).shuffle(p)
    return pre, p, cnt


def null_weight(pre, post, cnt, seed):
    a = np.abs(cnt)
    perm = np.random.default_rng(seed).permutation(a.size)
    return pre, post, (np.sign(cnt) * a[perm]).astype(cnt.dtype)


def neuron_signs(pre, cnt, n):
    """Per-neuron sign (+1/-1) for every neuron with outgoing edges, 0 otherwise.
    Raises if a presynaptic neuron has edges of both signs (Dale's law violated in the input)."""
    s = np.zeros(n, dtype=np.int8)
    sg = np.sign(cnt).astype(np.int8)
    s[pre] = sg
    if not np.array_equal(s[pre], sg):
        raise ValueError("input data has a presynaptic neuron with mixed signs")
    return s


def null_sign(pre, post, cnt, seed, n):
    s = neuron_signs(pre, cnt, n)
    has = np.nonzero(s != 0)[0]
    new = np.zeros_like(s)
    new[has] = np.random.default_rng(seed).permutation(s[has])
    return pre, post, (np.abs(cnt) * new[pre]).astype(cnt.dtype)


def interior_mask_boundary(pre, post, input_side, output_side):
    """Interior edge = presynaptic neuron not on the input side AND postsynaptic neuron not on the output side."""
    return ~input_side[pre] & ~output_side[post]


def null_masked(pre, post, cnt, seed, interior):
    """Permute post only among edges where interior is True."""
    p = post.copy()
    idx = np.nonzero(interior)[0]
    vals = p[idx]
    np.random.default_rng(seed).shuffle(vals)
    p[idx] = vals
    return pre, p, cnt


def null_boundary(pre, post, cnt, seed, input_side, output_side):
    m = interior_mask_boundary(pre, post, input_side, output_side)
    return null_masked(pre, post, cnt, seed, m)


def null_stimreadout(pre, post, cnt, seed, stim_idx, readout_idx, n):
    keep = np.zeros(n, dtype=bool)
    keep[np.asarray(stim_idx)] = True
    m = ~keep[pre] & (post != readout_idx)
    return null_masked(pre, post, cnt, seed, m)

def _deg(a, n):
    return np.bincount(a, minlength=n)

    key.sort()

def rates(trial):

    sc = 1000.0 / trial["dn"]["bin_ms"]

    for ct, sides in IDS.items():

    d = np.clip(raw, -CLIP, CLIP)
    return d, turn, raw

"""Synthetic-graph tests for nulls.py (no FlyWire data; seconds). Run: python -m pytest -q tests/test_nulls.py"""
import sys
from pathlib import Path

import numpy as np

sys.path.insert(0, str(Path(__file__).resolve().parents[1]))
import nulls  # noqa: E402

N = 200


def graph(seed=0, e=5000):
    rng = np.random.default_rng(seed)
    pre = rng.integers(0, N, e).astype(np.int32)
    post = rng.integers(0, N, e).astype(np.int32)
    sign = np.where(rng.random(N) < 0.6, 1, -1)  # one sign per neuron (Dale's law)
    cnt = (rng.integers(1, 50, e) * sign[pre]).astype(np.int32)
    return pre, post, cnt


def sides():
    inp = np.zeros(N, bool)
    inp[:20] = True
    out = np.zeros(N, bool)
    out[-15:] = True
    return inp, out


def test_degree():
    r = graph()
    n = nulls.null_degree(*r, seed=3)
    c = nulls.check("D", r, n, N)
    assert all(c.values()), c
    assert not np.array_equal(n[1], r[1])


def test_degree_matches_bootstrap_load_edges():
    r = graph()
    p = r[1].copy()
    np.random.default_rng(1).shuffle(p)
    assert np.array_equal(nulls.null_degree(*r, seed=1)[1], p)


def test_weight():
    r = graph()
    n = nulls.null_weight(*r, seed=101)
    c = nulls.check("W", r, n, N)
    assert all(c.values()), c
    assert not np.array_equal(n[2], r[2])


def test_sign():
    r = graph()
    n = nulls.null_sign(*r, seed=201, n=N)
    c = nulls.check("S", r, n, N)
    assert all(c.values()), c
    assert not np.array_equal(n[2], r[2])


def test_boundary():
    r = graph()
    inp, out = sides()
    n = nulls.null_boundary(*r, seed=301, input_side=inp, output_side=out)
    c = nulls.check("B", r, n, N, input_side=inp, output_side=out)
    assert all(c.values()), c
    assert not np.array_equal(n[1], r[1])


def test_stimreadout():
    r = graph()
    n = nulls.null_stimreadout(*r, seed=401, stim_idx=[0, 1, 2], readout_idx=N - 1, n=N)
    c = nulls.check("B'", r, n, N, stim_idx=[0, 1, 2], readout_idx=N - 1)
    assert all(c.values()), c


def test_checks_catch_violations():
    r = graph()
    inp, out = sides()
    bad = (r[0], np.random.default_rng(9).permutation(r[1]), r[2])  # full shuffle moves boundary edges
    assert not all(nulls.check("B", r, bad, N, input_side=inp, output_side=out).values())
    badw = (r[0], r[1], -r[2])  # flips every sign
    assert not nulls.check("W", r, badw, N)["edge_signs_kept"]
    mixed = r[2].copy()
    mixed[0] = -mixed[0]  # one edge of a neuron gets the other sign
    assert not nulls.check("S", r, (r[0], r[1], mixed), N)["one_sign_per_presynaptic_neuron"]
    shorter = (r[0][:-1], r[1][:-1], r[2][:-1])
    assert not nulls.check("D", r, shorter, N)["n_edges_kept"]


def test_structure_stats():
    pre = np.array([0, 0, 1, 2], np.int32)
    post = np.array([1, 1, 1, 2], np.int32)
    s = nulls.structure_stats(pre, post, 3)
    assert s == {"self_loops": 2, "duplicate_pairs": 1}
