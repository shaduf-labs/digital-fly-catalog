Build your own

Build your own fruit fly brain simulation: a tested beginner guide from an empty folder

Run the published whole-brain model of the fruit fly on an ordinary CPU. You give 21 sugar-sensing neurons a taste, the simulated brain of 138,639 neurons responds, and you read out the neuron that makes a fly extend its proboscis to feed. Then you change one thing and check the result against shuffled wiring.

  • Tested on: Linux x86_64 (Debian 12), Python 3.11.2, 2 CPUs, no GPU, no C++ compiler, 28 Sep 2026
  • Full run: 28 min for 20 one-second trials; tests 52 s
  • Untested: macOS, Windows/WSL, Colab, machines with a compiler
  • Pins: checked against PyPI on 30 Sep 2026: no pinned package has a newer release since our test; next full re-test due by 12 Oct 2026

In one paragraph

We ran this guide from an empty folder on 28 September 2026. With sugar neurons firing at 150 Hz, the proboscis motor neuron MN9 fired at 85.2 ± 3.2 Hz, so our rule said "extend the proboscis". With no stimulus nothing fired at all. With the same stimulus on shuffled wiring, MN9 stayed at 0 Hz in 6 of 6 trials, so the response depends on the real connectome. All 6 tests passed. We have not tried other operating systems, so we cannot promise it runs on yours; the untested parts are labelled on every step.

What you will build, and why this project

A small Python project, taste → action, that wraps the leaky integrate-and-fire (LIF) model of Shiu et al. (Nature 634, 210–219, 2024), philshiu/Drosophila_brain_model, pinned at commit 91bdd1e7, with the FlyWire connectome public release v783. We chose it because:

  • It is the real thing, and small enough. The whole adult brain wiring runs on a CPU, with about 105 MB of data.
  • It was tested against flies. The paper compared the model's predictions with experiments (grade A in our catalogue), so you have published numbers to compare with. Its requirements, known issues and the projects built on it are on its project page.
  • Most viral demos reuse it. Once you understand this project, you can read the code of DOOMFLY, Fly64 and many browser demos.
  • The code licence is MIT. The data licence is non-commercial; see the licence box.

What the model leaves out

This is a model, so it does not show what a living fly would do. In the authors' words, it "does not account for gap junctions, non-spiking neurons, internal state or long-range neuropeptides, and assumes that the basal firing of each neuron is zero". It has no neuromodulation, no learning (plasticity) and no body, and the transmitter signs are predictions. The authors say they do not trust absolute firing rates; compare patterns, not exact numbers.

How to tell it worked

  1. pytest prints 6 passed.
  2. With sugar at 150 Hz, MN9 fires at roughly 80–90 Hz and the action is "EXTEND proboscis".
  3. With no stimulus, nothing fires. The model has no spontaneous activity, so any spike there means a bug.
  4. With shuffled wiring, MN9 stays at 0 Hz while the sugar neurons still fire at about 147 Hz.

With the same seed, a 100 ms trial gave exactly 1,200 whole-brain spikes in three separate runs on our machine. Other CPUs or library versions may give slightly different spike counts (Untested).

Customize it

Open a Python prompt in the folder with .venv/bin/python, then:

import fly_taste as ft

# 1. Change the stimulus rate (tested: 50 Hz gave 16.6 ± 7.2 Hz)
r = ft.run_condition(ft.SUGAR_GRNS_V783, rate_hz=50, n_trials=5)
print(ft.rate_of(r, ft.MN9))

# 2. Silence a neuron (tested: this one cut MN9 by 34%)
r = ft.run_condition(ft.SUGAR_GRNS_V783, silence_ids=[720575940623211725], n_trials=5)
print(ft.rate_of(r, ft.MN9))
  • Silencing cuts outgoing synapses only. As in upstream silence(), only the synapses from the neuron are set to zero, although the upstream Readme says "to and from" (issue #10, open). To cut its inputs too, also zero syn.w['j == k'].
  • Why this neuron? run_demo.py picked it with our own rule: the input to MN9 with the largest synapse count × firing rate in the sugar run, not counting the sugar neurons. It makes 424 synapses onto MN9 (FlyWire cell type CB0553, predicted acetylcholine). Silencing it weakened MN9 but did not stop it, which suggests other excitatory routes. This is a model output; it is not one of the paper's experiments.
  • Other neurons: use v783 IDs. FlyWire IDs change when a neuron is edited. Look them up in FlyWire Codex with the version set to 783. The upstream notebooks list v630 IDs, and one sugar neuron changed: 720575940620900446 (v630) is 720575940639259967 in v783, as the upstream author wrote in issue #7. The other 20 sugar neurons and MN9 (720575940660219265) are unchanged.

The shuffled-wiring control, and why it matters

A shuffled brain keeps everything except who connects to whom. Our control randomly re-assigns the target of each of the 15.1 million connections (shuffle_seed=1 and 2). Every neuron keeps its number of inputs and outputs, and its outgoing weights and sign, so excitatory neurons stay excitatory.

Result: with the same 150 Hz sugar stimulus, MN9 went from 85.2 Hz to 0 Hz in 6 of 6 trials. The sugar neurons still fired at about 147 Hz, but activity reached only 120–126 neurons instead of 409. So the response depends on the specific wiring, not only on the number or strength of connections. This matches the direction of the paper (shuffled weights activated MN9 in 1 of 100 runs) and of the drosophila-brain-mlx port (0 Hz); we did not re-run those.

This is the test most viral demos skip. When you see a "fly brain" play a game, ask whether it still plays with shuffled wiring. See Is it real? for the demos we checked. We tested only one kind of shuffle; others, such as a weight-only shuffle, are Untested. With only 2 shuffles, our run is a clean but small result; Does fly wiring help? compares it with 30 other control studies and gives a four-point checklist for a fairer control (3 or more shuffles of each kind, the same tuning, a no-brain baseline).

What the six tests check

The tests use short runs (1 trial × 200 ms), so the whole file took 52 s for us.

  1. Checksum of Completeness_783.csv: you have exactly the neuron list we used.
  2. Checksum of Connectivity_783.parquet: you have exactly the wiring we used.
  3. All IDs exist in v783: the 21 sugar neurons and MN9 are present, and the file has 138,639 neurons. This catches the v630 ID problem.
  4. No stimulus gives silence: zero spikes in the whole brain, and the action is "stay still".
  5. Sugar drives MN9: at 150 Hz, MN9 fires above 20 Hz and the action is "EXTEND proboscis".
  6. Shuffled wiring changes the readout: on shuffled wiring MN9 stays below 20 Hz, and a different set of neurons fires.

FlyGym 2.1.0 smoke test script (tested 2026-09-28, CPU, no rendering) 
"""FlyGym 2.1.0 CPU smoke test: build NeuroMechFly on flat ground, step physics, no rendering.
Construction follows FlyGym's own tests/conftest.py at tag v2.1.0."""
import time, resource
t0 = time.time()
import flygym, mujoco
from flygym.anatomy import AxisOrder, JointPreset, ActuatedDOFPreset, Skeleton
from flygym.compose.fly import NeuroMechFly, ActuatorType
from flygym.compose.world import FlatGroundWorld
from flygym.compose.pose import KinematicPosePreset
from flygym.utils.math import Rotation3D
from flygym.simulation import Simulation
print(f"mujoco {mujoco.__version__}; import {time.time()-t0:.1f} s")
pose = KinematicPosePreset.NEUTRAL.get_pose_by_axis_order(AxisOrder.YAW_PITCH_ROLL)
skel = Skeleton(axis_order=AxisOrder.YAW_PITCH_ROLL, joint_preset=JointPreset.LEGS_ONLY)
fly = NeuroMechFly(name="fly")
fly.add_joints(skel, neutral_pose=pose)
fly.add_actuators(skel.get_actuated_dofs_from_preset(ActuatedDOFPreset.LEGS_ACTIVE_ONLY),
                  ActuatorType.POSITION, neutral_input=pose, kp=50)
fly.add_leg_adhesion(gain=1.0)
world = FlatGroundWorld()
world.add_fly(fly, spawn_position=[0, 0, 1.5], spawn_rotation=Rotation3D("quat", [1, 0, 0, 0]))
t1 = time.time()
sim = Simulation(world)
sim.reset()
m = sim.mj_model
print(f"compiled: nq={m.nq} nu={m.nu} nbody={m.nbody} timestep={m.opt.timestep} s in {time.time()-t1:.1f} s")
z0 = float(sim.mj_data.qpos[2]); n = 2000
t2 = time.time()
for _ in range(n):
    sim.step()   # no control written: position actuators hold the neutral pose
dt = time.time() - t2

fly_taste.py: loads the wiring, builds the network, runs trials (245 lines) 
"""Taste -> action with the Shiu et al. whole-brain LIF model (FlyWire v783).

What this file does
-------------------
1. Loads the FlyWire v783 connectivity published in philshiu/Drosophila_brain_model
   (measured wiring: who connects to whom, how many synapses, excitatory/inhibitory sign).
2. Builds the same leaky integrate-and-fire (LIF) network as upstream model.py
   (modelled dynamics: equations and parameters are imported from upstream, not copied).
3. Drives chosen sugar-sensing gustatory receptor neurons (GRNs) with Poisson spikes
   (hand-made stimulus: which neurons and what rate are our choice, following the paper).
4. Reads out the firing rate of MN9, the motor neuron for proboscis extension
   (hand-made readout choice, following the paper).
5. Maps the rate to an action with a threshold (hand-made rule, not part of the model).

Differences from upstream run_exp (see README "What's real here"):
- Only the three columns the model uses are loaded, as int32/float arrays, to save memory.
- The connectivity file is streamed in chunks (same synapse order) to keep peak memory under 1 GB.
- Each trial runs in a fresh worker process with an explicit random seed (repeatable runs).
- Brian2 runs with the pure-numpy code generation target when no C++ compiler exists.
"""
from __future__ import annotations

import multiprocessing
import os
import shutil
import sys
import time
from concurrent.futures import ProcessPoolExecutor

import numpy as np
import pyarrow as pa

from model import default_params  # noqa: E402  (upstream model.py, pinned commit)

CONNECTIVITY = UPSTREAM / "Connectivity_783.parquet"

# https://github.com/philshiu/Drosophila_brain_model/issues/7

    720575940617000768, 720575940630797113, 720575940632889389, 720575940621754367,

def pick_codegen_target() -> str:
    """Cython (fast) if a C++ compiler is on PATH, else pure numpy (slower, needs no compiler).

    Override with the environment variable FLY_CODEGEN=numpy or FLY_CODEGEN=cython.
    """
    forced = os.environ.get("FLY_CODEGEN")
    if forced:
        return forced
    if any(shutil.which(c) for c in (os.environ.get("CXX", ""), "g++", "clang++", "c++") if c):
        # keep Brian2's compiled-code cache inside the project (works on read-only homes too)
        b2.prefs.codegen.runtime.cython.cache_dir = str(HERE / ".cython_cache")
        return "cython"
    return "numpy"


def load_ids() -> np.ndarray:
    """FlyWire root IDs in model order (row i of the CSV = Brian2 neuron index i)."""
    ids = np.loadtxt(COMPLETENESS, delimiter=",", skiprows=1, usecols=0, dtype=np.int64)
    return ids


def _read_column(name, dtype):
    """Read one parquet column row group by row group into a compact numpy array."""
    f = pq.ParquetFile(CONNECTIVITY, memory_map=False)
    out = np.empty(f.metadata.num_rows, dtype=dtype)
    k = 0
    for g in range(f.num_row_groups):  # streaming keeps peak memory low
        col = f.read_row_group(g, columns=[name]).column(0).to_numpy()
        out[k:k + col.size] = col
        k += col.size
        del col
    assert k == out.size
    return out


def load_edges(shuffle_seed: int | None = None):
    """Return (pre, post) neuron indices of every connection, as int32.

    shuffle_seed: if given, build the degree-preserving control by randomly permuting
    the postsynaptic column in place. Every neuron keeps its number of outgoing and
    incoming connections, and every presynaptic neuron keeps its own weights and sign
    (so excitatory neurons stay excitatory), but who-connects-to-whom is randomised.
    """
    pre = _read_column("Presynaptic_Index", np.int32)
    post = _read_column("Postsynaptic_Index", np.int32)
    if shuffle_seed is not None:
        np.random.default_rng(shuffle_seed).shuffle(post)
    return pre, post


def load_signed_counts():
    """Upstream's 'Excitatory x Connectivity' column: synapse count x (+1 excitatory,
    -1 inhibitory). The sign comes from the predicted neurotransmitter of the presynaptic
    neuron (acetylcholine = +1; GABA and glutamate = -1)."""
    return _read_column("Excitatory x Connectivity", np.float64)


def load_connectivity(shuffle_seed: int | None = None):
    pre, post = load_edges(shuffle_seed)
    return pre, post, load_signed_counts()


def build_network(params, exc, slnc, shuffle_seed=None):
    """Build the upstream LIF network (same as create_model() + poi() + silence() in
    upstream model.py), streaming the connectivity file in chunks to keep memory low."""
    n = len(load_ids())
    neu = b2.NeuronGroup(
        N=n, model=params["eqs"], method="linear",
        threshold=params["eq_th"], reset=params["eq_rst"], refractory="rfc",
        name="default_neurons", namespace=params,
    )
    neu.v = params["v_0"]
    neu.g = 0 * mV
    neu.rfc = params["t_rfc"]
    syn = b2.Synapses(neu, neu, "w : volt", on_pre="g += w",
                      delay=params["t_dly"], name="default_synapses")
    f = pq.ParquetFile(CONNECTIVITY, memory_map=False)
    post_all = load_edges(shuffle_seed)[1] if shuffle_seed is not None else None
    k = 0
    for g in range(f.num_row_groups):  # connect chunk by chunk (same order as upstream)
        t = f.read_row_group(g, columns=["Presynaptic_Index", "Postsynaptic_Index"])
        pre = t.column(0).to_numpy().astype(np.int32)
        post = (post_all[k:k + pre.size] if post_all is not None
                else t.column(1).to_numpy().astype(np.int32))
        del t
        syn.connect(i=pre, j=post)
        k += pre.size
    del post_all
    w_syn = float(params["w_syn"])  # 0.275 mV, in volts
    k = 0
    for g in range(f.num_row_groups):  # weight = signed synapse count x w_syn
        c = f.read_row_group(g, columns=["Excitatory x Connectivity"]).column(0).to_numpy()
        syn.w_[k:k + c.size] = c * w_syn
        k += c.size
    for i in slnc:  # same as upstream silence(): zero all synapses *from* neuron i
        syn.w[f"i == {i}"] = 0 * mV
    pois = []
    for i in exc:   # same as upstream poi()
        pois.append(b2.PoissonInput(target=neu[i], target_var="v", N=1,
                                    rate=params["r_poi"],
                                    weight=params["w_syn"] * params["f_poi"]))
        neu[i].rfc = 0 * ms
    mon = b2.SpikeMonitor(neu, record=False)  # spike counts only, saves memory
    return b2.Network(neu, syn, mon, *pois), mon, len(syn)


def _one_trial(params_r_poi_hz, exc, slnc, shuffle_seed, rand_seed, t_run_ms):
    """Build the network, run one trial, return (spike counts, n_synapses, build s, run s).
    Runs in a fresh worker process so all memory is returned after each trial
    (upstream does the same via joblib)."""
    params = dict(default_params)  # upstream constants and equations
    params["r_poi"] = params_r_poi_hz * Hz
    b2.prefs.codegen.target = pick_codegen_target()
    b2.start_scope()
    t0 = time.time()
    net, mon, n_syn = build_network(params, exc, slnc, shuffle_seed)
    t1 = time.time()
    b2.seed(rand_seed)
    net.run(t_run_ms * ms)
    return np.asarray(mon.count[:], dtype=np.int32), n_syn, t1 - t0, time.time() - t1


def run_condition(stim_ids, rate_hz=150.0, silence_ids=(), n_trials=3, t_run_ms=1000.0,
                  seed=0, shuffle_seed=None, verbose=True):
    """Run one experimental condition; return per-trial spike counts for all neurons.

    Like upstream run_trial(), the network is rebuilt for every trial (a few seconds),
    one trial at a time (peak memory about 0.6 GB). Trial k uses Brian2 random seed
    (seed * 1000 + k) for the Poisson input, so runs are repeatable.
    """
    ids = load_ids()
    id2i = {int(f): i for i, f in enumerate(ids)}
    exc = [id2i[int(f)] for f in stim_ids]          # KeyError here = ID not in v783
    slnc = [id2i[int(f)] for f in silence_ids]

    counts = np.zeros((n_trials, len(ids)), dtype=np.int32)
    build_s = sim_s = 0.0
    ctx = multiprocessing.get_context("spawn")
    for trial in range(n_trials):
        with ProcessPoolExecutor(max_workers=1, mp_context=ctx) as ex:
            c, n_syn, tb, tr = ex.submit(_one_trial, rate_hz, exc, slnc, shuffle_seed,
                                         seed * 1000 + trial, t_run_ms).result()
        counts[trial] = c
        build_s += tb
        sim_s += tr
        if verbose:
            print(f"  trial {trial + 1}/{n_trials}: {len(ids)} neurons, {n_syn} synapses, "
                  f"{int(c.sum())} spikes; build {tb:.1f} s, run {tr:.1f} s "
                  f"(target={pick_codegen_target()})", flush=True)
    return {
        "ids": ids, "counts": counts, "t_run_s": t_run_ms / 1000.0,
        "build_s": build_s, "sim_s": sim_s, "target": pick_codegen_target(),
        "stim_rate_hz": rate_hz, "n_trials": n_trials, "seed": seed,
        "shuffle_seed": shuffle_seed, "silenced": [int(s) for s in silence_ids],
    }


def rate_of(result, flywire_id):
    """Mean and s.d. firing rate (Hz) across trials for one neuron."""
    i = int(np.nonzero(result["ids"] == flywire_id)[0][0])
    r = result["counts"][:, i] / result["t_run_s"]
    return float(r.mean()), float(r.std())


def proboscis_action(mn9_rate_hz, threshold=PROBOSCIS_THRESHOLD_HZ):
    """Hand-made action mapping: extend the proboscis if MN9 fires above threshold."""
    return "EXTEND proboscis" if mn9_rate_hz > threshold else "stay still"


def top_active(result, n=10, exclude=()):
    mean = result["counts"].mean(axis=0) / result["t_run_s"]
    order = np.argsort(-mean)
    out = []
    ex = set(int(e) for e in exclude)
    for i in order:
        if mean[i] <= 0 or len(out) >= n:
            break
        if int(result["ids"][i]) in ex:
            continue
        out.append((int(result["ids"][i]), float(mean[i])))
    return out

def strongest_active_input_to_mn9(res):
    """Our (hand-made) choice of neuron to silence: the MN9 input partner with the largest
    (synapse count x firing rate) in the sugar run, excluding the stimulated GRNs."""
    pre, post, wsc = ft.load_connectivity()
    i_mn9 = int(np.nonzero(res["ids"] == ft.MN9)[0][0])
    sel = post == i_mn9
    p, w = pre[sel], wsc[sel]
    rate = res["counts"].mean(axis=0) / res["t_run_s"]
    grn_idx = {int(np.nonzero(res["ids"] == g)[0][0]) for g in ft.SUGAR_GRNS_V783}
    best, best_score = None, 0.0
    for k, wk in zip(p, w):
        score = wk * rate[k]
        if int(k) not in grn_idx and score > best_score:
            best, best_score = int(k), score
    return int(res["ids"][best]), float(best_score), int(sum(w[p == best]))

def sha256(path):
    h = hashlib.sha256()
    with open(path, "rb") as f:
        for block in iter(lambda: f.read(1 << 20), b""):
            h.update(block)
    return h.hexdigest()

                            seed=0, shuffle_seed=1)
    mn9_real, _ = ft.rate_of(sugar, ft.MN9)
    mn9_ctrl, _ = ft.rate_of(ctrl, ft.MN9)
    # same stimulus, same degrees and weights, different wiring -> MN9 no longer driven
    assert mn9_ctrl < ft.PROBOSCIS_THRESHOLD_HZ < mn9_real
    # and the set of active neurons is different
    act_real = set(np.nonzero(sugar["counts"].sum(axis=0))[0])
    act_ctrl = set(np.nonzero(ctrl["counts"].sum(axis=0))[0])
    assert act_real != act_ctrl
