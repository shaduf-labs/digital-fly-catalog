Research report · 28 September 2026 · second check

Second check: 15 new fruit fly brain projects, a Doom control study and two viral claims that do not hold up

Our first scheduled re-check of the catalogue. We re-checked all 58 entries and 40 videos, added 15 new projects and 4 videos, fixed one text, and wrote two project pages. The most important new finding: in Doom, a brainless autopilot survives about as long as the viral full-brain fly.

  • Run: run:98ee92ee-abef-44f6-8c98-42ce102025b7
  • Research time: 28 Sep 2026, 15:08–15:33 UTC
  • Catalogue version: 2026-09-28-run2 (73 entries)
  • Gallery: 44 videos

Short answer

Nothing changed in the 58 existing entries, and that is expected: this re-check came only about 22 hours after the first pass. No entry had a new commit, release, licence change or archive change; every main link and all 40 videos still answered.

15 new entries, graded from files we opened: 5 A, 1 B, 5 C, 2 D and 2 not graded. Most of the A grades are control studies. The key one, doom-fly-control, found that a brainless autopilot survives in Doom about as long as DOOMFLY's full-brain simulation (51.9 s against 53.3 s).

Two viral demos do not hold up in the code. The Half-Life video (137,648 views) says it uses the MaleCNS v1.0 connectome, but by default the released code builds its own synthetic network (grade D). The Minecraft farming video (FlyBridge, grade C) trains a 1,536-neuron part of the connectome, and scripted code does the walking, aiming and clicking.

Borderline grades

  • Fly Self Driving (A): the headline and rewired-graph numbers appear only in the project's results document (docs/results.md), and the stored baseline JSON does not match that document.
  • fly-brain by erojas and Kick the Fly (C): the neural parts alone could argue for B, but the behaviour shown is triggered, scripted motion.
  • Null models at the sensory-motor boundary (A): the brain is heavily compressed, to 512 cell-type groups.
  • flydoom (mutkuoz) and FlyWire neuron annotations have no licence file, so reuse of their code is not clearly allowed.

No grade of an existing entry changed. No tracked code changed, and no new claim contradicts an existing grade. The Doom control study adds evidence against the viral "fly plays Doom" framing and fits DOOMFLY's grade B; it cannot raise it.

The main finding: a constant autopilot plays Doom about as well

The real wiring matters for producing any output: shuffled or disconnected brains hardly move. But the output is close to a constant "turn slightly right, walk, shoot" command, and a constant command does as well in this arena. The autopilot's constants were taken from the real fly's average output, so the test shows that a constant policy reproduces the behaviour, not that the brain does nothing. The shuffled groups are small (4 runs per seed), and a control with matched activity is still missing.

On the site: the Doom test and updated verdict on Is it real?, two new verdict rows (Half-Life, Minecraft farming), five new rows in the controlled-studies table, and the new DOOMFLY project page.

Method

Tracking

  • Last commits come from fresh shallow clones of each default branch; last releases from each repository's release feed; archive status from the repository page.
  • Our GitHub API allowance was low (60 calls), so for the 58 existing entries we reused stars, creation dates and last-push dates from our 27 Sep check. Each record says so (api_fields_reused_from), and the catalogue shows it next to the stars.
  • Every main link and every video was checked again over HTTP (videos through the platforms' embed-information services or a partial file download).

Grading new entries

  • Each grade rests on files we opened, cited with line numbers, and every entry has at least one source we read ourselves.
  • We re-opened the key files ourselves for every A and B grade and for the Half-Life D grade.
  • The 5 C grades rest on file citations from a short first reading (about 3 minutes per repository). We spot-read them but did not re-verify them line by line.
  • Videos were used for claims only, never for a grade.

Limits and uncertainty

  • All numbers are author-measured (a third party's for doom-fly-control). We did not reproduce any of them. Several controls are small: a single training seed, 4 runs per shuffle seed, 2 races.
  • No browser. Demos such as the Fly Self Driving site and Virtual Fly Brain are recorded as "page responds, not played by us". We did not watch any video frame by frame.
  • Short interval. Only about 22 hours passed since the first pass, so "no changes" says little about how fast the field moves.
  • Reused dates. Stars, creation dates and last-push dates for the 58 existing entries are from 27 Sep 2026 and labelled as such. Archive status and last commits are fresh.
  • Borderline and quickly read grades: see the new entries. The C grades were spot-read, not re-verified line by line.
  • Sweep gaps. X and TikTok could not be searched without logging in, so they were not searched. 211 repositories that appear only in project directories were not triaged yet.
  • Video details. For project-hosted files the date is the commit date; two lengths are not stated by their hosts.
  • Virtual Fly Brain's MCP server is VFB's own service. We did not test it, and Digital Fly Lab offers no API or MCP server of its own.
