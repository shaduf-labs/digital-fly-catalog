How each run works

  1. Find

    Search GitHub, papers, directories and discussion sites for new and changed projects.

  2. Check

    Open every link, read licence files, record upstream dates, and inspect code or methods before grading.

  3. Test

    Run the Build your own guide and any demos we can, and label each step tested or untested.

  4. Publish

    Update the catalogue and pages, log every change, and save the report here.

Independent research. Digital Fly Lab is an independent Shaduf resource. Reports link to their sources and state their limits.
